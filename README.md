## 🎯 Mục tiêu học GitHub
Để xây dựng một nền tảng vững chắc cho sự nghiệp công nghệ, mình đặt ra các mục tiêu cụ thể khi làm việc với GitHub:
- **Thành thạo công cụ quản lý mã nguồn:** Làm chủ các luồng làm việc cơ bản và nâng cao với Git (Clone, Commit, Push, Pull, Branching, Merging, Conflict Resolution).
- **Xây dựng quy trình phối hợp nhóm chuyên nghiệp:** Thành thạo cách quản lý dự án, làm việc cộng tác thông qua Pull Requests, Code Review, Issues và GitHub Projects.
- **Xây dựng Portfolio cá nhân:** Biến trang cá nhân GitHub thành một "bản CV số" trực quan, lưu trữ các sản phẩm, đồ án chất lượng để kết nối với cộng đồng và nhà tuyển dụng.
- **Tiếp cận tự động hóa (CI/CD):** Tìm hiểu và áp dụng thử nghiệm GitHub Actions để tự động hóa quy trình kiểm thử và triển khai ứng dụng.

## 🛠️ Kỹ năng muốn rèn luyện
Dưới đây là lộ trình các kỹ năng mình tập trung trau dồi và tối ưu hóa trong thời gian tới:

### 1. Kỹ năng Kỹ thuật & Chuyên môn (Hard Skills)
* **Tư duy lập trình vững chắc:** Nâng cao kỹ năng xử lý logic, cấu trúc dữ liệu và giải thuật với `Python` và `JavaScript / Node.js`.
* **Phát triển Web Toàn diện:** Thành thạo thiết kế giao diện chuẩn responsive (HTML/CSS, các kỹ thuật căn chỉnh bố cục nâng cao) kết hợp quản trị cơ sở dữ liệu hệ thống (MySQL, MongoDB).
* **Kỹ thuật Phần cứng & IoT:** Rèn luyện tư duy thiết kế mạch vi điều khiển, kỹ năng hàn mạch, viết mã nguồn điều khiển phần cứng và mô phỏng hệ thống robot.

### 2. Kỹ năng Mềm & Quy trình làm việc (Soft Skills)
* **Quản lý mã nguồn & Kiểm soát phiên bản:** Biến Git thành thói quen hàng ngày trong mọi dự án lớn nhỏ độc lập hoặc đội nhóm.
* **Kỹ năng làm việc nhóm (Teamwork):** Giao tiếp hiệu quả với cộng sự, học cách phân chia module công việc bài bản và hỗ trợ gỡ lỗi chéo.
* **Tự học & Giải quyết vấn đề (Problem-solving):** Nâng cao năng lực đọc hiểu tài liệu kỹ thuật, kỹ năng tìm kiếm giải pháp tối ưu trên StackOverflow/GitHub Issues và chủ động xử lý lỗi hệ thống.
